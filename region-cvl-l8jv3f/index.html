2Entraînement

Vos documents entraînent-ils le modèle ?

Le verrou est posé par défaut, sauf un cas à régler.

  • Claude : non, sauf un retour envoyé
  • Mistral Enterprise : désactivé par défaut
  • Mistral Team : à verrouiller par l'administrateur
  • Copilot : non, selon la documentation Microsoft

Sources : privacy.claude.com (18/08/2026) ; help.mistral.ai/en/articles/455207 (03/09/2026) ; learn.microsoft.com, Copilot privacy (04/11/2026).

6Ma proposition

Deux usages, un test

Ces rôles sont une hypothèse de départ : c'est le test qui les confirmera ou non.

  • Claude : construire l'outil
  • Copilot : le travail de bureau
  • Mistral : le repli si l'Europe est exigée
  • Cinq documents anonymisés, trois outils

AXEM accompagne un centre de gestion sur Claude : d'où ce test sur les trois outils, sur vos propres documents.

Ce que je n'ai pas pu vérifier

La qualité des trois outils sur vos propres documents : c'est le but du test. Les limites de pages de l'application Claude. Les rapports de certification des trois éditeurs.
