        Ce qu'il faut savoir : sur cette page, le cerveau est une grille de règles écrite pour ce scénario. Il est instantané, mais il ne comprend que les phrases d'un plombier. Dans le vrai produit, le cerveau sera un modèle de langage. On a mesuré le petit modèle open source dans le tableau ci-dessous : il comprend l'action, mais il faut un modèle plus gros pour remplir un devis sans erreur.

        Démo de travail : client, adresses, numéros et prix sont inventés. Aucun SMS, aucun mail, aucun paiement ne part de cette page.
